# Avant-première — Portfolio de Pinel LOKONON

Portfolio one-page au thème « théâtre / avant-première » (bordeaux, crème, serif éditorial), construit avec React + TypeScript + Vite + Lenis.

```bash
npm install
npm run dev      # développement
npm run build    # build de production (dossier dist/)
```

- `src/data.ts` : toutes les informations (profil, projets, compétences, expériences, formations)
- `src/App.tsx` : sections (hero, prologue, programme, acte I, acte II, cast, backstage, curtain call)
- `src/styles.css` : design system (couleurs, typographies, grain, animations)
- `public/assets/` : photos, captures de projets et CV
